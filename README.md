# Rabi Dahal — Industrial Brutalist Portfolio

Personal portfolio of **Rabi Dahal**, embedded systems, IoT & automation engineer. A static, scroll-driven one-pager with a WebGL arc-reactor disc, Web Audio synth, a custom reticle cursor, a VEKTOR guide character, and live GitHub integration.

Live at: [https://rabidahal.com.np](https://rabidahal.com.np) → mirror at [https://proobker.github.io/](https://proobker.github.io/)

## Tech stack

- **HTML5 + CSS3 + vanilla JavaScript** (ES modules, no framework)
- **Three.js** — background WebGL reactor disc (via import map, runtime CDN)
- **Google Fonts** — Space Grotesk (display) + IBM Plex Mono (technical text)
- **GitHub API** — live user stats; project data from a committed `projects.json`

No build step, no bundler, no transpilation.

## Design language

"Industrial engineering document" / experimental brutalist.

- Mid-industrial gray base (`#2E2C28`), warm cream ink (`#EFE9DC`), industrial orange accent (`#FF4D00`)
- Hard rectangles everywhere — `border-radius: 0` enforced globally
- Subtle diagonal stripes on the base; hazard stripes in select decorative strips
- 12-column hairline grid overlay (background layer only, never over content)
- Oversized Space Grotesk headlines, dense IBM Plex Mono metadata
- Section watermarks (`01`–`08`), registration corner marks, hard rules, offset blocks

## Features

- **Boot sequence** intro overlay with load bar (`00 / INTRO`)
- **WebGL arc reactor** — spinning disc in the hero, tilt follows the mouse, spin accelerates with scroll
- **Custom reticle cursor** that enlarges over interactive elements (hidden on touch devices)
- **Magnetic buttons** and hover/click Web Audio blips (mute toggle, top-right)
- **VEKTOR guide character** — drawn + typed narration per section
- **Count-up stat counters** triggered on scroll into section `03`
- **Floating project previews** that follow the cursor over project rows
- **Timeline** with a scroll-progress fill
- **Live GitHub stats** (repos, followers, last updated) with offline fallbacks
- **Accent color control** — "vibe" presets interpolate a CSS custom property live
- **Responsive** desktop left-rail nav + mobile hamburger menu
- **Noscript fallback** — content still accessible without JavaScript

## How project data works

`assets/projects.json` is the single source for the ARC gallery (04), the major-projects table (05), and the GitHub repo list (07). It is generated by `.github/scripts/refresh-projects.mjs`, which reads a curated `MANIFEST` of 8 repos from the GitHub API. `script.js` loads it; if the fetch fails it falls back to an embedded dataset so the UI always renders.

Regenerate it locally (no token required for public repos):

```bash
node .github/scripts/refresh-projects.mjs
```

The GitHub Action runs the same script nightly and commits any diff.

## Run locally

Open `index.html` directly in a browser. No server or build step needed.

## Deploy to GitHub Pages

1. Commit and push to `main`.
2. GitHub Pages already serves from the `main` branch at the repo root.
3. The `CNAME` file routes `rabidahal.com.np`; the fallback mirror is `proobker.github.io`.

Push to `main` and GitHub serves the static files directly — no Actions build is required for the site itself.

## Customizing

- **Palette / theme** — edit the custom properties in `:root` of `styles.css` (`--bg`, `--fg`, `--panel`, `--accent`, …)
- **Default accent** — default RGB in `script.js` (accent interpolation) and the first vibe button in `index.html`
- **Projects shown** — edit `MANIFEST` in `.github/scripts/refresh-projects.mjs`, then re-run the script
- **GitHub fallback repos** — `fallbackProjectsData` in `script.js`
- **VEKTOR narrations / section text** — `vektorNarrations` in `script.js`; copy lives in `index.html`
